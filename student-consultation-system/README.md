# Student Consultation Booking System

## Stack
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## Pages
- `index.php`
- `about.php`
- `register_student.php`
- `register_lecturer.php`
- `book_consultation.php`
- `view_bookings.php`
- `contact.php`

## Setup
1. Put this folder in your web server root (for example `htdocs` in XAMPP).
2. Start Apache and MySQL.
3. Import `database.sql` into MySQL.
4. Update DB credentials in `config/db.php` if needed.
5. Open `http://localhost/ict312/student-consultation-system/index.php`.
